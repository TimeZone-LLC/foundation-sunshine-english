# Foundation Sunshine NVIDIA RTX Video components

This directory is managed by Foundation Sunshine and its Control Panel. It is not a general-purpose DLL search path. Sunshine recognizes only the fixed file roles and trusted hashes supported by the installed release.

## Files and ownership

| File | Role | Ownership and terms |
| --- | --- | --- |
| `foundation_rtx_video_adapter.dll` | Foundation Sunshine adapter for the NVIDIA SDK | Project-authored GPL-3.0 code, installed with Sunshine and loaded only when RTX HDR is selected |
| `nvngx_truehdr.dll` | NVIDIA NGX runtime for SDR-to-HDR processing | NVIDIA material governed by the terms supplied by NVIDIA; not licensed under Foundation Sunshine's GPL-3.0 license |
| `component.json` | Local compatibility and integrity metadata | Generated by the Control Panel; it does not grant rights to any DLL |

Sunshine resolves the adapter from this fixed component directory, verifies the build-specific SHA-256 embedded in `sunshine.exe`, and loads it through a stable C ABI. The installer does not bundle the Microsoft Visual C++ runtime required by the adapter. Install the Microsoft Visual C++ 2015-2022 Redistributable (x64) when the Control Panel reports that prerequisite as missing.

The project source, including the adapter, is available at:

https://github.com/TimeZone-LLC/foundation-sunshine-english

Foundation Sunshine license:

https://github.com/TimeZone-LLC/foundation-sunshine-english/blob/master/LICENSE

The current Foundation Sunshine integration implements only SDR-to-HDR through `nvngx_truehdr.dll`. NVIDIA's published RTX Video SDK capabilities do not imply that every listed effect is implemented or supported by this Sunshine release.

Adapter builds made with the development NGX Application ID `0` expire fourteen days after they are built. An adapter built with an NVIDIA-assigned Application ID does not use this development expiry.

If you convey the project-authored adapter or a modified version of it, the GPL-3.0 requirements applicable to that covered code continue to apply, including preservation of notices and availability of corresponding source. The actual license controls; this README does not add restrictions to GPL-3.0 or decide whether a separate work forms a combined work.
